# Original input data

These files are copied byte-for-byte from the author-provided `Code/Code-Matlab/pso_data` and `M.png`; SHA256SUMS records their identities. No coordinate rounding, reprojection, simplification or attribute deletion is applied to this input archive.

The original manuscript attributes Railways, Building and Landuse to OpenStreetMap/Geofabrik (https://download.geofabrik.de), and Boundary, Road and Lake to China's National Geographic Information Catalogue Service (https://www.webmap.cn). All provided .prj files describe geographic coordinates in degrees. The manuscript reports WGS84 for the first group and CGCS2000 for the second.

OpenStreetMap data are © OpenStreetMap contributors and subject to their source licensing terms. The supplied files do not include a separate redistribution license from the Chinese source. Source terms continue to apply; the MIT software license does not apply to these datasets. Acquisition dates and original download package identifiers were not provided in this workspace.
